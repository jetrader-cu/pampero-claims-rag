# Pampero Claims Assistant

Asistente RAG multi-tenant para reclamaciones de seguros de vehículos.
Los ajustadores suben PDFs a su organización y hacen preguntas en lenguaje natural.
Cada respuesta trae citas verificables (documento, página y fragmento).

Stack: FastAPI · Celery + Redis · PostgreSQL + pgvector · React · OpenTelemetry.

> Trabajo en curso. Las instrucciones para levantar el sistema llegan con el primer servicio.
